## Overview

College application interface clone that mimics the Omnivox platform.

## Tech Stack

C#, SQL Server

## Features

- Login and signup
- Student-teacher interaction
- SQL Server database

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Ado-Omnivox.git
   ```
2. Open the `.sln` file in **Visual Studio**.
3. Update the SQL Server connection string if needed and create the database.
4. Press **F5** to build and run.
